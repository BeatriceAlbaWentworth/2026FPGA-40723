# 通用 FPGA 数据可视化与校验工具 (Visualize Results Skill)

## 1. 技能描述
这是一个基于 Python (`matplotlib`, `pandas`) 的自动化数据处理与可视化工具。它专为 FPGA 振动监测项目设计，能够自动读取 FPGA 回传的频谱 CSV 数据、特征数据集及分类结果，并生成标准化的分析图表。

## 2. 核心功能
本脚本集成了以下 5 大可视化模块，可直接用于设计报告或答辩演示：
- **系统架构绘制**：自动生成包含 PC、UART、FPGA (FIR/FFT) 流程的系统框图。
- **频谱对比分析**：自动读取 Normal/Looseness/Unbalance 三种状态的频谱数据并叠加绘图。
- **特征分布箱线图**：可视化 H2, H3, RMS 等关键特征在不同故障类型下的分布差异。
- **混淆矩阵热力图**：直观展示分类算法的准确率与误判情况。
- **性能指标看板**：自动渲染系统延迟、吞吐量等关键性能指标。

## 3. 适用范围
- **适用场景**：FPGA 信号处理结果验证、故障诊断模型评估、系统性能测试报告生成。
- **数据格式**：支持标准 CSV 格式，具备智能列名识别功能（自动匹配 frequency, magnitude 等列）。
- **环境依赖**：Python 3.x, numpy, pandas, matplotlib。

## 4. AI 协作提炼点 (AI Collaboration)
本工具是团队利用大模型进行“复杂工程代码生成”的典型实践：
1. **Prompt 策略**：采用了“角色设定+任务拆解”的提示词策略。我们要求 AI 扮演“数据可视化专家”，并将复杂的绘图需求拆解为“架构图”、“频谱图”、“混淆矩阵”等独立函数模块。
2. **智能容错设计**：针对 FPGA 导出数据列名不统一的问题，通过 AI 辅助编写了 `find_column` 模糊匹配算法，使脚本能自动适应不同的 CSV 表头，极大地提高了工具的通用性。
3. **代码迭代**：在生成“系统架构图”时，初版代码布局混乱。通过向 AI 提供“节点坐标计算逻辑”的反馈，AI 优化了 `np.linspace` 布局算法，实现了节点的自动对齐与美观排版。

## 5. 使用方法
1. **准备数据**：确保项目目录下存在 `outputs/fpga/` 等文件夹及对应的 CSV 数据文件。
2. **安装依赖**：`pip install matplotlib pandas numpy`
3. **运行脚本**：`python visualize_results.py`
4. **查看结果**：生成的图片将保存在 `outputs/` 目录下，命名为 `video_01_...` 至 `video_05_...`。

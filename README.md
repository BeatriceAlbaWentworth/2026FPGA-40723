# 2026FPGA-40723
2026FPGA-40723团队项目工程
项目名称：基于FPGA的振动监测系统
团队编号：40723
开发部型号：Zynq-7020
项目简介：本项目设计并实现了一套基于 FPGA 的高速振动监测与异常识别系统，面向电机、风扇及小型机械设备，旨在解决传统处理器在高频振动信号处理上的实时性瓶颈。系统通过加速度传感器实时采集设备的原始振动数据，并送入 FPGA 进行全硬件流水线处理。首先，利用片上 DSP 资源构建 FIR 数字滤波器，有效滤除环境噪声与高频干扰；随后，调用高性能 FFT 模块 将时域信号转换为频域频谱。在此基础上，系统通过硬件逻辑实时提取主频、频谱能量、峰值等关键特征，并依据预设阈值快速判别设备处于正常、松动、不平衡或异常振动状态，实现微秒级的故障响应。最终，处理结果与状态标识通过高速接口传输至上位机，由 Python 程序进行实时波形可视化与状态报警。本系统充分发挥了 FPGA 并行计算与高确定性的优势，为工业旋转机械的预测性维护提供了一种低功耗、高可靠的边缘监测方案。

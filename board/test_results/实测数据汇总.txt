 上板实测数据汇总
 平台：正点原子 ZYNQ7020 最小系统板（XC7Z020-2CLG400I）
 日期：2026-10-31 ~ 2026-11-02
========================================================

一、环境配置
--------------------------------------------------------
  FPGA 器件      : xc7z020clg400-2（实物 XC7Z020-2CLG400I）
  PL 时钟        : 50.000 MHz（引脚 U18，板载有源晶振）
  串口           : 921600 8N1，外接 CH340 模块，端口 COM8
  采样率         : 2000 Hz
  每帧样本数     : 1024 点 int16
  调试接口       : JTAG（FT2232H），ILA 4 探针 / 深度 1024


二、时序与资源（Vivado 2025.1 实现后报告）
--------------------------------------------------------
  WNS            : +6.774 ns   （时钟周期 20 ns，余量 33.9%）
  TNS            :  0.000 ns   （零失败端点，共 29,569 个）
  WHS            : +0.050 ns

  Slice LUTs     :  4,771 / 53,200   =  8.97%
  Slice Registers:  9,734 / 106,400  =  9.15%
  Block RAM Tile :    6.5 / 140      =  4.64%
  DSP48          :     46 / 220      = 20.91%
  Bonded IOB     :      5 / 125      =  4.00%

  说明：LUT 中包含 ILA 调试核（约 722 LUT），去掉调试核约为 3,5xx。


三、功能验证（单频 125 Hz，输入幅值 9000）
--------------------------------------------------------
  峰值频点       : bin 64 → 125.00 Hz
  峰值 |X|       : 4,463,712
  与 Python 黄金模型比对：
      峰值频点    完全一致
      峰值幅度    4,463,712 vs 4,464,005，误差 0.007%
  频谱帧校验     : 通过（513 频点 × 8 字节 = 4104 字节）
  旁瓣电平       : 最大旁瓣 145,210，相对主峰 −29.7 dB（符合 Hamming 窗特性）


四、双音滤波实验（验证 FIR 在硬件中真实工作）
--------------------------------------------------------
  输入           : 125 Hz（幅值 6000）+ 800 Hz（幅值 3000）+ 高斯噪声
  截止频率       : 500 Hz

  125 Hz 分量    : 硬件 5807 / 模型 5807（完全一致）
  800 Hz 分量    : 硬件 1 / 模型 1（压到噪声底）
  800 Hz 衰减    : −73.5 dB
  硬件 vs 模型最大误差：0.0177%（相对主峰）


五、片内计时器（50 MHz，20 ns/周期）
--------------------------------------------------------
  tmr_drain      : 2,218 周期 = 44.36 µs
                   含义：最后一个有效输入样本 → 最后一个 FFT 输出握手
                   即 FPGA 流水线排空延迟

  tmr_cycles     : 1,225,584 周期 = 24.51 ms
                   含义：第一个样本进入 FIR → 最后一个 FFT 输出

  整帧窗口拆解：
      串口接收 2048 字节（理论）   1,111,111 周期   22.22 ms   90.7%
      USB/CH340 分包间隙             112,255 周期    2.25 ms    9.2%
      FPGA 流水线延迟                  2,218 周期   44.36 µs    0.18%
      ----------------------------------------------------------------
      合计                         1,225,584 周期   24.51 ms


六、端到端性能（PC 侧 Python 脚本实测）
--------------------------------------------------------
  往返回总耗时   : 71.7 ms（A 的 send_test.py 单帧）
                   67.2 ms 为串口传输（6189 字节 × 10 bit / 921600）
                   4.5 ms 为 USB 协议与 Python 读写开销
  有效帧率       : 13.95 帧/秒

  B 的批量测试（30 次平均）：
      PC 端到端平均耗时 : 125.017 ms
      P50 : 124.923 ms   P95 : 126.256 ms   P99 : 126.708 ms
      通信成功率 : 30/30，0 超时，0 重试

  软件 FIR+FFT（NumPy，1000 次）：0.03826 ms

  ⚠️ 口径说明：
      0.038 ms 是纯计算，不含串口；
      125 ms 是端到端，含串口与 PC 收发；
      44.36 µs 是 FPGA 内部流水线延迟。
      三者测量边界不同，不能直接计算加速比。


七、故障分类（30 份模拟振动数据）
--------------------------------------------------------
  样本分布       : 正常 10 / 松动 10 / 不平衡 10
  训练/测试划分  : 21 / 9
  判别特征       : rms_fpga_parseval、H2_ratio、H3_ratio
  判别阈值       : RMS = 5448.95   H2 = 0.1476   H3 = 0.0609
  测试集准确率   : 9/9 = 100%
  混淆矩阵       : 对角全 3，无错分

  各类别特征均值：
      类别          RMS       H2       H3
      正常        4492.7   0.0086   0.0044
      松动        4947.0   0.3295   0.1641    ← 谐波显著
      不平衡      6360.4   0.0069   0.0043    ← RMS 最高


八、测试结论
--------------------------------------------------------
  1. 真实 FPGA 的运算结果与 RTL 仿真、Python 黄金模型完全一致，
     不存在"仿真通过、硬件出错"的情况。
  2. FIR 滤波器在硬件中真实工作：截止频率外的 800 Hz 被压制 73.5 dB。
  3. FPGA 流水线延迟 44.36 µs，仅占整帧窗口的 0.18%；
     系统吞吐瓶颈在串口带宽（921600 bps），不在 FPGA 算力。
  4. 资源占用 LUT 8.97%、DSP 20.91%，时序余量 33.9%，仍有充足扩展空间。
